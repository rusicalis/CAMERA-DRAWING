HOOK 모바일 자동도면 v0.4.0 변경사항
=====================================
1. 제품명 변경
   - 화면/설치명/출력 파일의 기존 명칭을 "HOOK"로 통일

2. 치구번호 자동 넘버링
   - 기본 라인 코드: NNI, AG
   - 사용자 라인 코드 추가/저장 가능
   - 시작번호 + 촬영수 기준 연속 자동 번호 생성 (예: NNI-001 ~ NNI-010)
   - 촬영 사진별 치구번호 개별 수정 가능
   - 사용 완료 번호를 기기에 저장하여 다음 시작번호 추천

3. AR 자동 측정 보조
   - 지원되는 Android Chrome/WebXR 환경에서 평면 hit-test로 카메라-바닥 거리 및 화면 실폭을 자동 추정
   - AR 보정 후 같은 높이에서 촬영하면 격자판 없이 mm 스케일 보조 가능
   - iPhone Safari 등 WebXR 미지원 환경은 1cm 격자 또는 대략 폭/높이 입력 방식 사용
   - 자동 모드 우선순위: 사용자 대략치수 > 1cm 격자 > AR 보정

4. 일반 설계도면 스타일
   - A4 가로형 도면 프레임
   - 치수선/화살표/중심선 표시
   - 우하단 타이틀 블록 적용
   - 치구번호, 재질, Ø, 전개길이, 전체치수, 측정방식, 단위, 작성일, REV 표시

5. 개인정보/사진 처리
   - 앱 내부 카메라 촬영
   - 사진첩 저장 기능 없음
   - 서버 업로드 기능 없음
   - 분석 성공 후 촬영 원본 Blob 폐기
