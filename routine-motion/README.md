# Daily Routine Motion Assets

이 폴더는 DAILY ROUTINE 웹앱에서 자동으로 사용하는 운동 모션 MP4 전용 폴더입니다.
기존 CAMERA-DRAWING/index.html과 독립적으로 운영합니다.

## App motion files

- `pushup.mp4`
- `pushup-close.mp4`
- `kettlebell-row.mp4`
- `kettlebell-deadlift.mp4`
- `goblet-squat.mp4`
- `reverse-lunge.mp4`
- `shoulder-press.mp4`
- `lateral-raise.mp4`
- `face-pull.mp4` — 앱에서는 밴드 리버스 플라이 가이드로 사용
- `kettlebell-curl.mp4`
- `triceps-extension.mp4`
- `running.mp4`

앱 사용자는 영상 URL을 입력하거나 이 폴더를 직접 관리할 필요가 없습니다. `.github/workflows/bootstrap-routine-motion.yml`이 필요한 운동 모션 세트를 다시 구축할 수 있습니다.

영상 출처와 사용조건은 `LICENSES.md`를 확인합니다.
